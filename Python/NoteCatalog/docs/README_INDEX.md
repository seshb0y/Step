# 📚 Документация проекта "Киберпанк Каталог Заметок"

## 🎯 Обзор
Это полная документация для каждого файла проекта Django. Каждый README объясняет код простыми словами, с детальным описанием каждого класса, метода и ключевого слова.

## 📁 Структура документации

### 🏗️ Основные файлы Django

#### 📊 [models.py](models.py_README.md)
- **Что это**: Описание структуры данных в базе данных
- **Содержит**: Классы Note и Tag, поля моделей, связи
- **Ключевые понятия**: Model, CharField, TextField, DateTimeField, ManyToManyField, Meta, __str__, get_absolute_url

#### 🎭 [views.py](views.py_README.md)
- **Что это**: Контроллеры, обрабатывающие запросы пользователей
- **Содержит**: Классы для списка, деталки, создания, редактирования, удаления, поиска
- **Ключевые понятия**: ListView, DetailView, CreateView, UpdateView, DeleteView, LoginRequiredMixin, get_queryset, get_context_data

#### 📝 [forms.py](forms.py_README.md)
- **Что это**: HTML-формы для ввода данных
- **Содержит**: Класс NoteForm с валидацией
- **Ключевые понятия**: ModelForm, Meta, widgets, clean_title, ValidationError

#### 🛣️ [urls.py](urls.py_README.md)
- **Что это**: URL-маршруты, связывающие адреса с представлениями
- **Содержит**: Все маршруты сайта
- **Ключевые понятия**: path, urlpatterns, reverse, kwargs, параметры URL

#### 👨‍💼 [admin.py](admin.py_README.md)
- **Что это**: Настройки админ-панели Django
- **Содержит**: Классы TagAdmin и NoteAdmin
- **Ключевые понятия**: @admin.register, ModelAdmin, list_display, list_filter, search_fields

### 🔧 Дополнительные файлы

#### 📡 [signals.py](signals.py_README.md)
- **Что это**: Автоматические действия при событиях
- **Содержит**: Сигнал post_save для автоматического добавления тегов
- **Ключевые понятия**: @receiver, post_save, get_or_create, exists, add

#### 🏷️ [templatetags/](templatetags_README.md)
- **Что это**: Кастомные фильтры и теги для шаблонов
- **Содержит**: Фильтры readtime и highlight_search
- **Ключевые понятия**: @register.filter, re.sub, re.escape, регулярные выражения

#### 🎨 [templates/](templates_README.md)
- **Что это**: HTML-шаблоны для отображения страниц
- **Содержит**: Базовый шаблон, шаблоны заметок, компоненты
- **Ключевые понятия**: {% extends %}, {% block %}, {% include %}, {% for %}, {% if %}, {{ }}

#### 🧪 [tests.py](tests.py_README.md)
- **Что это**: Автоматические тесты для проверки работы приложения
- **Содержит**: Тесты моделей и представлений
- **Ключевые понятия**: TestCase, Client, setUp, assertEqual, assertContains, assertTemplateUsed

#### ⚙️ [settings.py](settings.py_README.md)
- **Что это**: Настройки Django проекта
- **Содержит**: Конфигурация базы данных, приложений, безопасности
- **Ключевые понятия**: INSTALLED_APPS, MIDDLEWARE, DATABASES, STATIC_URL, DEBUG
