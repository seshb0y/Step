## 🔧 Фильтр readtime (Время чтения)

```python
@register.filter
def readtime(text):
    """
    Оценивает время чтения текста на основе количества слов.
    Предполагается, что средняя скорость чтения составляет 200 слов в минуту.
    """
    if not text:
        return "~0 мин"
    
    # Удаляем HTML теги и считаем слова
    clean_text = re.sub(r'<[^>]+>', '', str(text))
    words = len(clean_text.split())
    
    # Средняя скорость чтения: 200 слов в минуту
    minutes = words / 200
    
    if minutes < 1:
        return "~1 мин"
    elif minutes < 2:
        return f"~{int(minutes)} мин"
    else:
        return f"~{int(minutes)} мин"
```

### 🔍 Детальное объяснение:

**`@register.filter`**
- `@` - синтаксис декоратора
- `register.filter` - декоратор для регистрации фильтра
- **Что происходит**: Регистрирует функцию как фильтр для шаблонов

**`def readtime(text):`**
- `def` - создание функции
- `readtime` - название фильтра
- `text` - параметр (текст для анализа)
- **Что происходит**: Функция принимает текст и возвращает время чтения

**`if not text:`**
- `if not text` - проверка на пустой текст
- **Что происходит**: Если текст пустой, возвращаем "~0 мин"

**`clean_text = re.sub(r'<[^>]+>', '', str(text))`**
- `re.sub()` - функция замены по регулярному выражению
- `r'<[^>]+>'` - регулярное выражение для HTML тегов
- `''` - замена на пустую строку
- `str(text)` - преобразование в строку
- **Что происходит**: Удаляем все HTML теги из текста

**`words = len(clean_text.split())`**
- `clean_text.split()` - разбить текст на слова
- `len()` - подсчитать количество слов
- **Что происходит**: Считаем количество слов в тексте

**`minutes = words / 200`**
- `200` - средняя скорость чтения (слов в минуту)
- **Что происходит**: Вычисляем время чтения в минутах

**`if minutes < 1: return "~1 мин"`**
- Если время меньше 1 минуты, показываем "~1 мин"

**`elif minutes < 2: return f"~{int(minutes)} мин"`**
- Если время меньше 2 минут, показываем округлённое время

**`else: return f"~{int(minutes)} мин"`**
- Иначе показываем округлённое время

### 🎯 Использование в шаблоне:
```html
{{ note.body|readtime }}
<!-- Результат: ~3 мин -->
```

## 🔍 Фильтр highlight_search (Подсветка поиска)

```python
@register.filter
def highlight_search(text, query):
    """
    Подсвечивает найденные слова в тексте.
    """
    if not query or not text:
        return text
    
    # Экранируем специальные символы в запросе
    escaped_query = re.escape(query)
    
    # Заменяем найденные слова на подсвеченные
    highlighted = re.sub(
        f'({escaped_query})',
        r'<mark>\1</mark>',
        str(text),
        flags=re.IGNORECASE
    )
    
    return highlighted
```

### 🔍 Детальное объяснение:

**`def highlight_search(text, query):`**
- `text` - текст для подсветки
- `query` - поисковый запрос
- **Что происходит**: Функция принимает текст и запрос, возвращает текст с подсветкой

**`if not query or not text:`**
- Проверяем, что есть и текст, и запрос
- **Что происходит**: Если чего-то нет, возвращаем исходный текст

**`escaped_query = re.escape(query)`**
- `re.escape()` - экранирование специальных символов
- **Зачем**: Чтобы поиск работал с любыми символами

**`highlighted = re.sub(...)`**
- `re.sub()` - замена по регулярному выражению
- **Что происходит**: Заменяем найденные слова на подсвеченные

**`f'({escaped_query})'`**
- `f'...'` - f-строка (форматирование)
- `({escaped_query})` - группа в регулярном выражении
- **Что происходит**: Создаём регулярное выражение для поиска

**`r'<mark>\1</mark>'`**
- `r'...'` - raw строка
- `<mark>` - HTML тег для подсветки
- `\1` - ссылка на первую группу (найденное слово)
- **Что происходит**: Заменяем найденное слово на `<mark>слово</mark>`

**`flags=re.IGNORECASE`**
- `re.IGNORECASE` - флаг игнорирования регистра
- **Что происходит**: Поиск без учёта регистра

### 🎯 Использование в шаблоне:
```html
{{ note.title|highlight_search:search_query|safe }}
<!-- Результат: <mark>Python</mark> программирование -->
```

## 🔧 Дополнительные возможности:

### 1. Фильтр с параметрами
```python
@register.filter
def truncate_words_custom(text, length):
    words = text.split()
    if len(words) <= length:
        return text
    return ' '.join(words[:length]) + '...'
```

### 2. Тег (более сложная логика)
```python
@register.simple_tag
def get_recent_notes(count=5):
    return Note.objects.all()[:count]
```

### 3. Включение тега
```python
@register.inclusion_tag('notes/note_card.html')
def render_note_card(note):
    return {'note': note}
```
