# tasks/__init__.py

## Назначение
Файл `__init__.py` делает папку `tasks` Python пакетом и Django приложением для управления задачами. Это пустой файл, который сообщает Python и Django, что данная директория должна рассматриваться как модуль для работы с задачами пользователей.

## Контекст и зависимости
- **Python** - интерпретатор языка
- **Django** - фреймворк для обнаружения приложений
- **Управление задачами** - система создания, редактирования и удаления задач

## Функциональность приложения tasks

### 1. Управление задачами
- **Создание задач** - добавление новых задач
- **Редактирование задач** - изменение названия и статуса
- **Удаление задач** - удаление ненужных задач
- **Изменение порядка** - drag & drop для сортировки

### 2. Фильтрация задач
- **Все задачи** - показ всех задач пользователя
- **Выполненные** - только завершенные задачи
- **Невыполненные** - только активные задачи

### 3. API endpoints
```
/api/tasks/
├── /                    # GET - список задач, POST - создание
├── {id}/               # GET/PUT/PATCH/DELETE - конкретная задача
└── reorder/            # PATCH - изменение порядка задач
```

## Структура приложения
```
tasks/
├── __init__.py          # Делает tasks пакетом
├── apps.py              # Конфигурация приложения
├── models.py            # Модель Task
├── views.py             # API представления
├── serializers.py       # Сериализаторы
├── urls.py              # URL маршруты
└── migrations/          # Миграции базы данных
```

## Связанные файлы
- `tasks/models.py` - модель данных Task
- `tasks/views.py` - API представления
- `tasks/serializers.py` - сериализаторы
- `todo_api/settings.py` - настройки проекта
