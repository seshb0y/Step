# 🚀 КИБЕРПАНК КАТАЛОГ ЗАМЕТОК

Футуристическое веб-приложение для создания и управления заметками с тегами, построенное на Django в стиле киберпанк.

## ✨ Возможности

### 🎯 Базовый функционал
- ✅ Просмотр списка всех заметок с пагинацией (5 заметок на страницу)
- ✅ Детальная страница заметки
- ✅ Фильтрация заметок по тегам
- ✅ Поиск по заголовку и содержимому заметок
- ✅ **Киберпанк дизайн** с неоновыми эффектами и анимациями

### 🔐 CRUD операции (для авторизованных пользователей)
- ✅ Создание новых заметок
- ✅ Редактирование существующих заметок
- ✅ Удаление заметок с подтверждением
- ✅ Flash-сообщения об успехе/ошибке операций
- ✅ Валидация уникальности заголовков

### 🚀 Продвинутые возможности
- ✅ **Кэширование** списка заметок на 60 секунд
- ✅ **Кастомный фильтр** `readtime` для оценки времени чтения
- ✅ **Подсветка поиска** с эффектом `<mark>`
- ✅ **Автоматические теги** через сигналы Django
- ✅ **Админ-панель** Django для управления данными
- ✅ **Адаптивный киберпанк дизайн** с неоновыми эффектами

## 🔧 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd NoteCatalog
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
```

### 3. Активация виртуального окружения

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/macOS:**
```bash
source venv/bin/activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Применение миграций
```bash
python manage.py migrate
```

### 6. Загрузка тестовых данных
```bash
python manage.py loaddata NoteCatalog/fixtures/notes.json
```

### 7. Создание суперпользователя
```bash
python manage.py createsuperuser
```

### 8. Запуск сервера разработки
```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

## 🌐 URL-маршруты

| URL | Описание |
|-----|----------|
| `/` | Список всех заметок |
| `/notes/<id>/` | Детальная страница заметки |
| `/notes/create/` | Создание новой заметки (требует авторизации) |
| `/notes/<id>/edit/` | Редактирование заметки (требует авторизации) |
| `/notes/<id>/delete/` | Удаление заметки (требует авторизации) |
| `/tags/<slug>/` | Заметки с определенным тегом |
| `/search/?q=...` | Поиск заметок |
| `/admin/` | Админ-панель Django |

## 📊 Модели данных

### Note (Заметка)
- `title` - заголовок (CharField, max_length=200)
- `body` - содержимое (TextField)
- `created_at` - дата создания (DateTimeField, auto_now_add=True)
- `updated_at` - дата обновления (DateTimeField, auto_now=True)
- `tags` - теги (ManyToManyField)

### Tag (Тег)
- `name` - название тега (CharField, max_length=50)
- `slug` - URL-слаг (SlugField, unique=True)
