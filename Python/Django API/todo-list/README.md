# Todo List - Полнофункциональное приложение для управления задачами

Это современное веб-приложение для управления задачами, построенное на Django REST API (бэкенд) и React + TypeScript + Vite (фронтенд).

## 🚀 Возможности

- ✅ **Добавление задач** - создание новых задач с валидацией
- ❌ **Удаление задач** - удаление ненужных задач с подтверждением
- ☑️ **Отметка выполнения** - переключение статуса задач
- 🔍 **Фильтрация** - просмотр всех, выполненных или невыполненных задач
- 🎯 **Drag & Drop** - изменение порядка задач перетаскиванием
- 🔐 **Аутентификация** - регистрация, вход и выход из системы
- 🌙 **Темы** - переключение между светлой и темной темой
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## 🛠 Технологии

### Бэкенд
- **Django 4.2** - веб-фреймворк
- **Django REST Framework** - API
- **Simple JWT** - аутентификация
- **CORS Headers** - настройка CORS
- **SQLite** - база данных (для разработки)

### Фронтенд
- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик
- **Tailwind CSS** - стилизация
- **Zustand** - управление состоянием
- **React Query** - работа с серверным состоянием
- **React Hook Form + Zod** - формы и валидация
- **DnD Kit** - drag & drop функциональность

## 🚀 Быстрый старт

### 1. Клонирование и настройка

```bash
cd todo-list
```

### 2. Настройка бэкенда (Django API)

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows)
.venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Применение миграций
python manage.py migrate

# Создание суперпользователя (опционально)
python manage.py createsuperuser

# Запуск сервера
python manage.py runserver
```

Бэкенд будет доступен по адресу: http://localhost:8000

### 3. Настройка фронтенда (React)

```bash
cd todo-ui

# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev
```

Фронтенд будет доступен по адресу: http://localhost:5173

## 📚 API Endpoints

### Аутентификация
- `POST /api/auth/register/` - Регистрация
- `POST /api/auth/login/` - Вход
- `POST /api/auth/refresh/` - Обновление токена
- `GET /api/auth/profile/` - Профиль пользователя

### Задачи
- `GET /api/tasks/` - Список задач (с фильтрацией по ?status=all|done|todo)
- `POST /api/tasks/` - Создание задачи
- `GET /api/tasks/{id}/` - Получение задачи
- `PATCH /api/tasks/{id}/` - Обновление задачи
- `DELETE /api/tasks/{id}/` - Удаление задачи
- `PATCH /api/tasks/reorder/` - Изменение порядка задач

## 🔧 Разработка

### Структура компонентов

- `AuthPanel` - панель аутентификации
- `AuthModal` - модальные окна входа/регистрации
- `TaskForm` - форма добавления задач
- `TaskItem` - элемент задачи с drag & drop
- `TaskList` - список задач с фильтрацией
- `FilterTabs` - вкладки фильтрации
- `ThemeToggle` - переключатель темы

### Управление состоянием

- **Zustand** для глобального состояния (аутентификация, UI)
- **React Query** для серверного состояния (задачи, API)
- **React Hook Form** для управления формами
