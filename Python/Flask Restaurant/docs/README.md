# Документация проекта Flask Restaurant API

## Обзор проекта

Этот проект представляет собой **REST API** (веб-сервис) для управления меню ресторана и информацией о поварах. API построен на фреймворке **Flask** - это популярный веб-фреймворк для Python, который позволяет создавать веб-приложения и API.

### Что такое REST API?
REST API - это способ общения между разными программами через интернет. Представьте, что у вас есть приложение на телефоне, которое показывает меню ресторана. Это приложение обращается к нашему API, чтобы получить список блюд, добавить новое блюдо или обновить информацию о поваре.

### Что такое Flask?
Flask - это инструмент для создания веб-приложений на Python. Это как конструктор для веб-сайтов и API. Flask позволяет:
- Создавать веб-страницы
- Обрабатывать HTTP-запросы (GET, POST, PUT, DELETE)
- Работать с базами данных
- Возвращать данные в формате JSON

## Основные возможности API

### Управление меню
- **GET** `/api/v1/menus/` - Получить список всех блюд
- **POST** `/api/v1/menus/` - Добавить новое блюдо
- **GET** `/api/v1/menus/{id}` - Получить конкретное блюдо
- **PUT** `/api/v1/menus/{id}` - Обновить блюдо полностью
- **PATCH** `/api/v1/menus/{id}` - Обновить блюдо частично
- **DELETE** `/api/v1/menus/{id}` - Удалить блюдо

### Управление поварами
- **GET** `/api/v1/chefs/` - Получить список всех поваров
- **POST** `/api/v1/chefs/` - Добавить нового повара
- **GET** `/api/v1/chefs/{id}` - Получить конкретного повара
- **PUT** `/api/v1/chefs/{id}` - Обновить повара полностью
- **PATCH** `/api/v1/chefs/{id}` - Обновить повара частично
- **DELETE** `/api/v1/chefs/{id}` - Удалить повара

### Дополнительные возможности
- Фильтрация по различным параметрам
- Сортировка результатов
- Пагинация (разбивка на страницы)
- Поиск по названию/имени
- Валидация данных
- Обработка ошибок

## Технологии

- **Python 3.11+** - Язык программирования
- **Flask** - Веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **Pydantic** - Валидация данных
- **Alembic** - Миграции базы данных
- **pytest** - Тестирование
- **Postman** - Тестирование API

## Как запустить проект

1. Установите Python 3.11+
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте базу данных: `alembic upgrade head`
4. Запустите приложение: `python run.py`
5. Откройте браузер: `http://localhost:5000`
