# requirements.txt - Зависимости проекта

## Описание файла

Файл `requirements.txt` содержит список всех внешних библиотек (пакетов), которые необходимы для работы нашего Flask приложения. Это стандартный способ в Python для указания зависимостей проекта.

## Что такое зависимости?

Зависимости - это готовые библиотеки кода, написанные другими разработчиками, которые мы используем в своем проекте. Вместо того чтобы писать все с нуля, мы используем готовые решения для:
- Создания веб-сервера (Flask)
- Работы с базами данных (SQLAlchemy)
- Валидации данных (Pydantic)
- Тестирования (pytest)

## Подробное описание каждой зависимости

### Веб-фреймворк и сервер
```txt
Flask==3.0.0
```
- **Flask** - основной веб-фреймворк для создания API
- **Версия 3.0.0** - конкретная версия для стабильности
- **Что делает**: Обрабатывает HTTP-запросы, создает веб-сервер

```txt
Gunicorn==21.2.0
```
- **Gunicorn** - WSGI HTTP сервер для продакшена
- **WSGI** - стандарт взаимодействия между веб-сервером и Python приложением
- **Что делает**: Запускает Flask приложение в продакшене

### Работа с базой данных
```txt
Flask-SQLAlchemy==3.1.1
```
- **SQLAlchemy** - ORM (Object-Relational Mapping) для работы с базами данных
- **ORM** - технология, которая позволяет работать с базой данных как с обычными Python объектами
- **Что делает**: Преобразует Python код в SQL запросы к базе данных

```txt
Flask-Migrate==4.0.5
```
- **Flask-Migrate** - инструмент для миграций базы данных
- **Миграции** - способ изменения структуры базы данных (добавление таблиц, колонок)
- **Что делает**: Создает и применяет изменения в структуре базы данных

### Валидация данных
```txt
Pydantic==2.5.0
```
- **Pydantic** - библиотека для валидации и сериализации данных
- **Валидация** - проверка правильности входящих данных
- **Сериализация** - преобразование данных в формат JSON
- **Что делает**: Проверяет, что данные соответствуют ожидаемому формату

### Конфигурация и переменные окружения
```txt
python-dotenv==1.0.0
```
- **python-dotenv** - загрузка переменных окружения из .env файла
- **Переменные окружения** - настройки, которые хранятся отдельно от кода
- **Что делает**: Загружает настройки из файла .env (например, пароли, URL базы данных)

```txt
python-decouple==3.8
```
- **python-decouple** - альтернативный способ работы с переменными окружения
- **Что делает**: Помогает отделить настройки от кода

### Тестирование
```txt
pytest==7.4.3
```
- **pytest** - фреймворк для тестирования Python кода
- **Тестирование** - проверка правильности работы кода
- **Что делает**: Запускает тесты и проверяет, что все работает правильно

```txt
pytest-cov==4.1.0
```
- **pytest-cov** - плагин для измерения покрытия кода тестами
- **Покрытие кода** - процент кода, который проверяется тестами
- **Что делает**: Показывает, какая часть кода покрыта тестами

```txt
httpx==0.25.2
```
- **httpx** - HTTP клиент для тестирования API
- **HTTP клиент** - инструмент для отправки HTTP запросов
- **Что делает**: Позволяет тестировать API изнутри тестов

### Качество кода
```txt
black==23.11.0
```
- **black** - автоматический форматировщик кода
- **Форматирование** - приведение кода к единому стилю
- **Что делает**: Автоматически исправляет отступы, пробелы, переносы строк

```txt
isort==5.12.0
```
- **isort** - сортировщик импортов
- **Импорты** - подключение внешних библиотек
- **Что делает**: Сортирует импорты в алфавитном порядке

```txt
ruff==0.1.6
```
- **ruff** - быстрый линтер для Python
- **Линтер** - инструмент для поиска ошибок и проблем в коде
- **Что делает**: Находит потенциальные ошибки и предлагает исправления

### Дополнительные инструменты
```txt
pre-commit==3.6.0
```
- **pre-commit** - хуки для Git
- **Git хуки** - автоматические действия перед коммитом
- **Что делает**: Автоматически запускает проверки кода перед сохранением

```txt
requests==2.31.0
```
- **requests** - HTTP библиотека для Python
- **Что делает**: Позволяет отправлять HTTP запросы из Python кода

## Как установить зависимости

```bash
# Установка всех зависимостей
pip install -r requirements.txt

# Или с использованием виртуального окружения (рекомендуется)
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Зачем нужен этот файл?

1. **Воспроизводимость** - любой разработчик может установить точно такие же версии библиотек
2. **Стабильность** - фиксированные версии предотвращают поломки при обновлениях
3. **Документация** - сразу видно, какие технологии используются в проекте
4. **Развертывание** - сервер может автоматически установить все зависимости

## Версионирование

В файле указаны конкретные версии библиотек (например, `Flask==3.0.0`). Это называется "закрепление версий" и обеспечивает:
- Предсказуемое поведение
- Отсутствие неожиданных поломок при обновлениях
- Возможность воспроизвести точно такую же среду разработки
